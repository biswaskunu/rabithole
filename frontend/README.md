# RabitHole Frontend

This is the React/TypeScript frontend repository. In a real monorepo setup, this would be `rabithole-web` - a separate repo from the backend (`rabithole-api`).

## Tech Stack
- React + TypeScript
- Vite (build tool)
- D3 or canvas for graph visualization
- Axios for API calls

## Local Development
```bash
cd frontend
npm install
npm run dev
```
